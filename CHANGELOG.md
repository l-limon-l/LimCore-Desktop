# Изменения

## 2.1.1 — 2026-10-04

- Исправлено закрытие меню выбора режима.
- Обновлён выбор приложений для прокси: иконки, список процессов, выбор файла.
- Подключение перезапускается автоматически после изменения настроек.

## 2.1.0 — 2026-10-02

- Добавлено окно с изменениями при выходе новой версии.
- Исправлено мерцание меню в трее.
- Кнопка «Отключить» перенесена под подключённый сервер.
- При отключённом VPN в трее отображается «Выберите сервер».
- Обновления доступны сразу после выхода.

## 2.0.1 — 2026-10-02

- Исправлено отображение флагов.
- Исправлено направление анимации перехода назад в настройках.
- Улучшена анимация меню в трее.
- При удалении программы можно удалить подписки и настройки.

## 2.0.0 — 2026-10-02

- Приложение переписано на C++/Qt.
- Трей: подписки, серверы, выбор режима и подключение из меню.
- Прокси для приложений по пути или имени, geo-файлы профилей маршрутизации.
- Настройка входящих подключений, уведомление об окончании подписки, новые флаги, анимации списка.

## 1.0.3 — 2026-10-01

- Ускорено скачивание обновлений.
- Уменьшен размер установщика.

## 1.0.2 — 2026-10-01

- Добавлен редактор конфигурации сервера и контекстное меню сервера.
- Выровнены размеры элементов интерфейса.
- Добавлена плавная прокрутка в списках и меню в трее.
- Исправлены артефакты при изменении размера окна и открытии меню в трее.
- Добавлены настройки резолвинга сервера, запуска в свёрнутом режиме и DNS для TUN.
- Добавлен выбор предпочитаемого типа IP.
- Исправлена работа TUN одновременно с другими VPN.

## 1.0.1 — 2026-10-01

- Режим Xray TUN включён по умолчанию.
- Режимы «Прокси» и «Xray TUN» включаются независимо на главном экране и в трее.
- Добавлены настройки типа DNS для TUN.
- Уровень логов ядра перенесён на экран логов.

## 1.0.0 — 2026-10-01

Первый релиз.

- Подписки и серверы: VLESS, VMess, Trojan, Shadowsocks, JSON-конфиги Xray.
- Режимы: системный прокси, TUN, смешанный, локальный прокси.
- Служба LimCore для работы TUN без прав администратора.
- Правила маршрутизации, прокси для приложений, фрагментация, мультиплексор.
- Меню в трее, логи, статистика, автообновление.
